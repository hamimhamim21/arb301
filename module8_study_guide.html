تَحْلِيلُ الفِعْلِ المُضَارِعِ - Present Verb Analysis

يَذْهَبُ = يـ (حَرْفُ المُضَارَعَةِ) + ذهب + ضَمِيرٌ مُسْتَتِرٌ

يَذْهَبُ = يـ (present tense prefix) + ذهب (root) + hidden pronoun

يَذْهَبُونَ = يـ (حَرْفُ المُضَارَعَةِ) + ذهب + و (فَاعِلٌ) + ن (عَلَامَةُ الرَّفْعِ)

يَذْهَبُونَ = يـ (prefix) + ذهب (root) + و (subject) + ن (sign of nominative)

إِعْرَابُ الفِعْلِ الأَمْرِ - I'rab of the Imperative Verb

What we will learn in Lesson 14: إعراب الفعل الأمر، المبتدأ النكرة، التعبير فإنّ

مُرَاجَعَةُ الإِعْرَابِ - I'rab Review

الفِعْلُ المَاضِي يَكُونُ دَائِمًا مَبْنِيًّا:

• مَبْنِيٌّ عَلَى الفَتْحِ: دَخَلَ المُعَلِّمُ الفَصْلَ، وَالوَلَدَانِ قَالَا الحَقَّ

Built on fathah: The teacher entered the classroom

• مَبْنِيٌّ عَلَى السُّكُونِ: فَهِمْنَا الدَّرْسَ، وَأَخَذْتُ الكِتَابَ

Built on sukoon: We understood the lesson, I took the book

• مَبْنِيٌّ عَلَى الضَّمِّ: الأَوْلَادُ حَفِظُوا الفَاتِحَةَ

Built on dammah: The children memorized Al-Fatihah

الفِعْلُ المُضَارِعُ - Present Tense Review

الأَصْلُ فِيهِ أَنْ يَكُونَ مَرْفُوعًا: يَقْرَأُ المُسْلِمُ القُرْآنَ، يَمْشِي الرَّجُلُ إِلَى المَسْجِدِ، الأَوْلَادُ يَلْعَبُونَ بِالكُرَةِ

The default is nominative: The Muslim reads the Quran, the man walks to the mosque, the boys play with the ball

وَقَدْ يَكُونُ مَنْصُوبًا إِذَا سَبَقَتْهُ أَدَاةٌ مِنْ أَدَوَاتِ النَّصْبِ

It can be accusative if preceded by a nasb particle

وَقَدْ يَكُونُ مَجْزُومًا إِذَا سَبَقَتْهُ أَدَاةٌ مِنْ أَدَوَاتِ الجَزْمِ (لَا النَّاهِيَة، لَمْ)

It can be jussive if preceded by a jazm particle (لَا الناهية, لَمْ)

القَاعِدَةُ العَامَّةُ - The General Rule

الفِعْلُ الأَمْرُ يُبْنَى عَلَى مَا يُجْزَمُ بِهِ مُضَارِعُهُ

The imperative verb is built on whatever its present tense is made jussive by

التَّفْصِيلُ - Details

• أَمَّا الفِعْلُ الأَمْرُ فَإِنَّهُ يَكُونُ دَائِمًا مَبْنِيًّا، فَهُوَ يُشْبِهُ الفِعْلَ المَاضِيَ

The imperative verb is ALWAYS indeclinable (مَبْنِيّ), like the past tense

• إِذَا كَانَ المُضَارِعُ يُجْزَمُ بِالسُّكُونِ → الأَمْرُ يُبْنَى عَلَى السُّكُونِ

If present is made jussive by sukoon → imperative is built on sukoon

مِثَالٌ: لَمْ يَفْهَمْ → اِفْهَمْ (فِعْلُ أَمْرٍ مَبْنِيٌّ عَلَى السُّكُونِ)

Example: لَمْ يَفْهَمْ → اِفْهَمْ (imperative built on sukoon)

مِثَالٌ: لَمْ يَقْرَأْ → اِقْرَأْ (فِعْلُ أَمْرٍ مَبْنِيٌّ عَلَى السُّكُونِ)

Example: لَمْ يَقْرَأْ → اِقْرَأْ (imperative built on sukoon)

مِثَالٌ: لَمْ يَخْرُجْ → اُخْرُجْ (فِعْلُ أَمْرٍ مَبْنِيٌّ عَلَى السُّكُونِ)

Example: لَمْ يَخْرُجْ → اُخْرُجْ (imperative built on sukoon)

الفِعْلُ المَجْزُوم إِعْرَابُهُ فِعْلُ الأَمْرِ إِعْرَابُهُ
لَمْ يَفْهَمْ فِعْلٌ مُضَارِعٌ مَجْزُومٌ وَعَلَامَةُ جَزْمِهِ السُّكُونُ اِفْهَمْ فِعْلُ أَمْرٍ مَبْنِيٌّ عَلَى السُّكُونِ
